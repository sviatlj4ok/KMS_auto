# Универсальный активатор для Windows и Office <br>
Этот активатор позволяет активировать Windows и Office разных версий без необходимости загружать дополнительное программное обеспечение. Все, что нужно, это запустить команду в командной строке и выбрать приложение для активации из удобного интерфейса.

### Совместимые версии Windows и Office<br>
#### Активатор поддерживает следующие версии Windows:<br>
Windows 10<br>
Windows 11<br>
Windows 10 LTSC 2021<br>
#### А также следующие версии Office:<br>
Office 2021<br>
Office 2019<br>
Office 2016<br>
Office 2013<br>
Visio 2021<br>
Visio 2019<br>
Visio 2016<br>
Project 2021<br>
Project 2019<br>
Project 2016<br>
#### А еще он может удалить все лицензии Office16.<br>
### Использование<br>
Для запуска не нужно ничего скачивать. Нужно выполнить всего одну команду:<br>

`powershell -command "iwr -useb https://raw.githubusercontent.com/mudachyo/kotanoffActivator/main/kotanoffActivator.ps1 | iex"` <br>
Далее выберите приложение, которое вам нужно активировать из удобного интерфейса. И все! Скриншот активатора Скриншот результата
